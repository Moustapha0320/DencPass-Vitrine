# Internationalisation FR/EN — Site vitrine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Denc-Vitrine marketing site fully browsable in French (default) and English, with dedicated `/en/...` URLs mirroring every existing French route, using react-i18next.

**Architecture:** `react-i18next` + `i18next-browser-languagedetector` read a per-page JSON translation namespace (`src/locales/{fr,en}/<page>.json`) plus a shared `common.json` for the layout. Every route in `src/App.jsx` gets an `/en/...` twin rendering the exact same page component — no page is ever duplicated. Blog and changelog data (plain JS arrays, not JSX) become parallel `*.fr.js` / `*.en.js` files keyed by the same `slug`/`id`.

**Tech Stack:** React 19, Vite 5, react-router-dom v7, `i18next`, `react-i18next`, `i18next-browser-languagedetector`.

**Spec:** `docs/superpowers/specs/2026-08-21-i18n-fr-en-design.md`

## Global Constraints

- No page component is ever duplicated between languages — same `.jsx` file renders both `/foo` and `/en/foo`.
- `/` (and its `/en` twin) is the only pair with no further path segment; every other route keeps its exact French slug (`/pricing`, `/security`, etc.) — English routes do NOT get translated slugs (`/en/pricing`, not `/en/prix`), to keep the mirroring mechanical and unambiguous.
- No auto-redirect based on browser language on first load. `/` always renders French.
- Every translation key must exist in BOTH `fr` and `en` JSON files before a task is considered done — never ship a namespace with English keys missing (falls back to French, that's fine as noted per-task) but never ship French keys missing from the English file's structure.
- All English copy is authored copy (adapted voice, not literal word-for-word), never a placeholder.
- `npm run build` must succeed after every task.

## Task 2: `useDocumentTitle` hook — per-page title, meta description, hreflang, html lang

**Files:**
- Create: `src/hooks/useDocumentTitle.js`

**Interfaces:**
- Consumes: `i18n.language` from `src/i18n.js` (Task 1).
- Produces: `useDocumentTitle(title, description, alternatePath)` — a hook every page task (5-15) calls once at the top of its component. `alternatePath` is the CURRENT page's French path without a locale prefix, e.g. `'/pricing'` or `'/blog/proteger-acces-organisation'` — the hook derives both hreflang URLs from it (`https://dencpass.com<path>` for fr, `https://dencpass.com/en<path>` for en).

- [ ] **Step 1: Write the hook**

Create `src/hooks/useDocumentTitle.js`:

```js
import { useEffect } from 'react'
import { useTranslation } from 'react-i18next'

const SITE_URL = 'https://dencpass.com'

function upsertMeta(attr, value, content) {
  let el = document.querySelector(`meta[${attr}="${value}"]`)
  if (!el) {
    el = document.createElement('meta')
    el.setAttribute(attr, value)
    document.head.appendChild(el)
  }
  el.setAttribute('content', content)
}

function upsertLink(rel, hreflang, href) {
  let el = document.querySelector(`link[rel="${rel}"][hreflang="${hreflang}"]`)
  if (!el) {
    el = document.createElement('link')
    el.setAttribute('rel', rel)
    el.setAttribute('hreflang', hreflang)
    document.head.appendChild(el)
  }
  el.setAttribute('href', href)
}

/**
 * Sets <title>, meta description, <html lang>, and hreflang alternate links
 * for the current page. Call once per page component, after useTranslation().
 *
 * @param {string} title - already-translated page title (e.g. t('pricing:meta.title'))
 * @param {string} description - already-translated meta description
 * @param {string} alternatePath - French path with no /en prefix, e.g. '/pricing' or '/' or '/blog/some-slug'
 */
export default function useDocumentTitle(title, description, alternatePath) {
  const { i18n } = useTranslation()

  useEffect(() => {
    document.title = title
    upsertMeta('name', 'description', description)
    document.documentElement.lang = i18n.language

    const frPath = alternatePath === '/' ? '/' : alternatePath
    const enPath = alternatePath === '/' ? '/en' : `/en${alternatePath}`
    upsertLink('alternate', 'fr', `${SITE_URL}${frPath}`)
    upsertLink('alternate', 'en', `${SITE_URL}${enPath}`)
  }, [title, description, alternatePath, i18n.language])
}
```

  const { pathname } = useLocation()
